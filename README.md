# 💰 SUPRA Trekk — Трекер расходов

Мобильное приложение для учёта личных расходов на **SwiftUI**.

![Иконка](MyFirstApp/Assets.xcassets/AppIcon.appiconset/icon_1024.png)

## 📱 Возможности

- ✅ Добавление расходов с названием, суммой и категорией
- ✏️ **Редактирование** существующих расходов (тап по карточке)
- 🗑 Удаление расходов (долгое нажатие)
- 🏷 **Категории:** 🍔 Еда, 🚗 Транспорт, 🏠 Жильё, 🎉 Развлечения, 📦 Другое
- 🔍 **Фильтр по категориям** — показ расходов только выбранной категории
- 📅 **Фильтр по датам** — Все / Сегодня / Неделя / Месяц
- 📊 **Круговая диаграмма** расходов по категориям (Swift Charts)
- 💰 **Бюджет на месяц** с прогресс-баром и цветовой индикацией
- 📤 **Экспорт в CSV** — выгрузка расходов в файл
- 🗑 Кнопка «Очистить всё»
- 📭 **Пустой экран** с иконкой и подсказкой
- 🎨 **Тёмная и светлая тема** — автоматическая адаптация
- ✨ **Анимации** — плавное появление карточек и прогресс-бара
- 📳 **Haptic feedback** — вибрация при действиях (на реальном iPhone)
- 🔥 **Собственная иконка** — SUPRA Trekk

## 🛠 Технологии

- **Swift 5** + **SwiftUI**
- **Swift Charts** — визуализация данных
- **UserDefaults** — локальное хранение расходов и бюджета
- **MVVM-подобная структура** — разделение на `Models/` и `Views/`

## 📂 Структура проекта

MyFirstApp/
├── Models/
│   └── Expense.swift          ← модель данных (Category, Expense, DateFilter)
├── Views/
│   ├── BudgetView.swift       ← бюджет на месяц с прогресс-баром
│   ├── ChartView.swift        ← круговая диаграмма
│   ├── EditExpenseView.swift  ← форма редактирования расхода
│   ├── EmptyStateView.swift   ← пустой экран
│   ├── ExpenseCard.swift      ← карточка расхода
│   └── ExportHelper.swift     ← экспорт в CSV + ShareSheet
└── ContentView.swift          ← главный экран

1. Клонируй репозиторий:
