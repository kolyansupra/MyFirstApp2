# 💰 MyFirstApp — Трекер расходов

Мобильное приложение для учёта личных расходов на **SwiftUI**.

## 📱 Возможности

- Добавление расходов с названием, суммой и категорией
- Категории: 🍔 Еда, 🚗 Транспорт, 🏠 Жильё, 🎉 Развлечения, 📦 Другое
- Фильтр расходов по категориям
- Круговая диаграмма расходов (Swift Charts)
- Итоговая сумма (общая и по фильтру)
- Сохранение данных между запусками (UserDefaults)
- Удаление расходов долгим нажатием
- Кнопка «Очистить всё»
- Адаптация под светлую/тёмную тему

## 🛠 Технологии

- **Swift 5** + **SwiftUI**
- **Swift Charts** — для визуализации
- **UserDefaults** — для локального хранения
- **MVVM-подобная структура**: `Models/` и `Views/`

## 📂 Структура проекта

MyFirstApp/
├── Models/
│   └── Expense.swift          ← модель данных (Category + Expense)
├── Views/
│   ├── ExpenseCard.swift      ← карточка расхода
│   └── ChartView.swift        ← круговая диаграмма
└── ContentView.swift          ← главный экран

## 🚀 Как запустить

1. Клонируйте репозиторий.
2. Откройте `MyFirstApp.xcodeproj` в Xcode.
3. Выберите симулятор (iPhone 17 Pro или новее).
4. Нажмите ▶️ для запуска.
